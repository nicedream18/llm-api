# 管理台前端改版验收

## 目标与边界

默认浅色、支持中性深色；正文 14px、标题 24px、36px 控件和等宽数字。按四组组织导航，列表优先、编辑使用侧边抽屉。保留现有权限、配额和服务端协议。

## 节点记录

### 第一批：框架与渠道

- de6f0d1：导航分组、主题记忆、渠道筛选与编辑抽屉、模型标签、行操作收纳及登录页。
- 初次验证：38 项 React 测试、TypeScript、生产构建通过。
- 后续复验补充：共享焦点管理、表格外操作浮层、固定侧栏账号入口。

### 第二批：访问密钥、上游账号、路由与日志

- 列表采用紧凑表格、筛选、明确主操作和分页；编辑及日志详情使用抽屉。
- 现有密钥编辑不重置用量、不回传掩码；新密钥仍仅创建时显示。
- 上游账号保留授权、批量启停、归档/恢复、同步与事件记录。操作菜单使用 portal，避免被滚动表格裁切。
- 路由策略白名单序列化保持不变；预演与保存独立。
- 抽屉自动聚焦、循环 Tab、Escape 关闭、背景 inert，关闭后恢复焦点。
- 列表失败与加载状态分开，提供重试。
- 验证：44 项 React 测试通过；TypeScript 和 Vite 生产构建通过；git diff --check 通过。
- 浏览器：实际运行编译后的管理台，在本机隔离服务中检查密钥表格与抽屉、上游账号菜单、深色路由及日志页面。演示数据为合成数据，未连接真实 Provider，不代表 OAuth/MySQL 联调验收。

### 第三批：待完成

- 仪表盘指标、请求趋势、渠道状态、近期错误、待审批和无请求引导。
- 运营统计图表、知识库/工具操作布局、Wiki/MCP 主题与移动布局收口。
- 桌面及移动端浏览器回归与最终全量质量门禁。

## 失败修正记录

- 初始旧测试仍查找旧按钮名称，按新可访问名称更新，并增加实际交互断言。
- 路由测试曾误提交预演表单，改为明确的编辑表单选择器。
- 浏览器发现操作菜单被表格裁切，使用共享 ActionMenu 及定向测试解决。
- 浏览器发现抽屉焦点停留背景、侧栏账号被挤出视口，增加 DialogA11y 与固定侧栏布局。
