## 复现命令

在已安装 requirements 的环境运行：

~~~bash
python -m pytest -q
node --test tests/frontend/*.test.cjs
python -m compileall -q app tests
git diff --check
~~~

真实 MySQL 测试需要专用测试服务器 socket：

~~~bash
WALIAPI_TEST_MYSQL_SOCKET=/path/to/isolated/mysql.sock python -m pytest -q
~~~

浏览器 QA 专用启动器 tests/support/run_mysql_app.py 只使用上述测试 socket，自建随机测试数据库。管理员密码写入 WALIAPI_TEST_PASSWORD_FILE 指定的临时文件，结束时清理。不应指向现有生产实例。
